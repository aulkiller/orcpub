# User Personas

## Player

**Role**: D&D 5e player using the app as their character sheet at the table

**Characteristics**:
- Owns one or more characters
- Uses Play Mode during sessions to track HP, spell slots, resources
- Looks up spell/ability rules text mid-session
- May join a campaign for real-time sync with DM
- Uses mobile phone at the table (responsive UI important)
- May use homebrew classes (e.g., Blood Hunter)

**Goals**:
- Quick access to character state during play
- Accurate auto-calculation when toggling equipment or using abilities
- Read rules text without leaving the app
- Track resources without manual math errors

**Frustrations**:
- Slow UI when needing quick reference
- Having to switch between apps for rules lookup
- Manual tracking errors for complex resource interactions

---

## Dungeon Master (DM)

**Role**: Runs the game session, manages encounters, oversees player characters

**Characteristics**:
- Creates and manages campaigns
- Invites players and views their character states in real-time
- Builds encounters using the compendium
- Tracks initiative and monster HP during combat
- Takes session notes
- Primarily uses desktop/laptop

**Goals**:
- See all player HP/conditions/resources at a glance without asking
- Quick encounter setup with CR validation
- Reference monster/spell stats during play
- Keep session notes in one place

**Frustrations**:
- Players forgetting to report HP changes
- Manual CR calculation
- Switching between multiple tools (encounter tracker, notes, monster stats)
